# Sudo Sapient Website

Marketing site for **Sudo Sapient**, an AI transformation studio. Built with **Next.js 15**
(App Router), **React 19**, **TypeScript** and **Tailwind CSS**. The stickman animations
are **Rive** files generated by scripts in `scripts/rive/`.

## Quick start

```bash
npm install
npm run dev -- -p 4000
```

Open `http://localhost:4000`. The `dev` script is plain `next dev` (port 3000 by default);
the team passes `-p 4000`.

## Scripts

| Script                                    | Does                                                                        |
| ----------------------------------------- | --------------------------------------------------------------------------- |
| `npm run dev`                             | Local dev server                                                            |
| `npm run build` / `npm run start`         | Production build / serve it                                                 |
| `npm run lint` / `npm run lint:fix`       | ESLint                                                                      |
| `npm run typecheck`                       | `tsc --noEmit`                                                              |
| `npm run format` / `npm run format:check` | Prettier write / check                                                      |
| `npm run test` / `npm run test:watch`     | Vitest                                                                      |
| `npm run validate`                        | typecheck, lint, test, build. Run before every deploy                       |
| `npm run rive:<name>`                     | Rebuild `public/rive/<name>.riv` from `scripts/rive/<name>.mjs`             |
| `postinstall` (automatic)                 | Copies `rive.wasm` from `@rive-app/canvas` into `public/rive/` (gitignored) |

Rive scripts: `rive:hero`, `rive:strike`, `rive:portfolio`, `rive:transform`,
`rive:testimonials`, `rive:cta`, `rive:footer`, `rive:climber`, `rive:services`,
`rive:about`. See `docs/RIVE.md`.

## Stack

- Next.js 15 App Router, React 19, TypeScript, Tailwind CSS 3
- Rive (`@rive-app/react-canvas`) for the stickman scenes; `.riv` files generated with
  `rive-mcp-server`'s writer (devDependency)
- Framer Motion for UI motion; GSAP (ScrollTrigger, DrawSVG) for the ladder climber, the
  text reveals and the SVG fallback scenes; OGL for the WebGL grid in the home hero
- Radix UI (`Select`, `Slot`), `class-variance-authority`, `tailwind-merge`
- Fonts (`next/font/google` in `app/layout.tsx`):

| Font             | CSS variable     | Tailwind class | Used for                      |
| ---------------- | ---------------- | -------------- | ----------------------------- |
| Instrument Serif | `--font-serif`   | `font-serif`   | Headlines and statement lines |
| Archivo Black    | `--font-display` | `font-display` | Card titles, wordmark         |
| Archivo          | `--font-grotesk` | `font-sans`    | Body copy                     |
| IBM Plex Mono    | `--font-mono`    | `font-mono`    | Labels and technical text     |

## Contact

The contact page has no form. Two buttons open WhatsApp (`wa.me/918050029848`, with a
prefilled hello) and email (a `mailto:` to `sudosapient@gmail.com` with a subject and a
short template). The number, address and message live at the top of
`app/(marketing)/contact/page.tsx`. Nothing is sent through this site and no environment
variables are needed.

## Copy rules

The owner wants all copy to follow these:

- No dashes as connectors (no em or en dashes between clauses). Use a full stop or a comma.
- No arrow characters.
- Never say "product".
- Position the studio as **AI transformation**: we sit with the team, learn how the work
  really gets done, automate the busywork with AI agents, and hand it over.

## SEO and GEO

Search engines and AI assistants (ChatGPT, Claude, Perplexity, Google AI Overviews) read
the same signals, all generated from `lib/seo.ts`:

- **Per page metadata:** every page exports `pageMetadata({ title, description, path })`,
  which sets its own title, description, canonical URL and social card. Never hard code a
  canonical in `app/layout.tsx`; it would point every page at the homepage.
- **Structured data (JSON-LD):** `Organization` and `WebSite` on every page (root layout),
  `Service` and `FAQPage` on Services (built from the visible `services` and `faqs`
  arrays), the team on About, breadcrumbs on interior pages. Rendered by
  `components/seo/JsonLd.tsx`. Keep schema facts identical to the visible copy.
- **`app/robots.ts` and `app/sitemap.ts`:** generate `/robots.txt` (everyone, AI crawlers
  included, may crawl) and `/sitemap.xml`. Add new public pages to `PAGES` in the sitemap.
- **`public/llms.txt`:** a plain summary for AI assistants. Update it when services, the
  process, FAQs or contact details change.
- **`public/og.png`:** the 1200 × 630 social share image (a real PNG, so link previews work
  on GitHub Pages).
- The parked `/work/<slug>` case studies are `noindex` and left out of the sitemap.
- **Service pages:** `/services/<slug>/` are generated from `lib/services.ts` (one search
  intent per page, with its own FAQs and schema). Add a service there and it gets a page,
  sitemap entry and card link.
- **Google Analytics 4:** set `GA_ID` in `lib/seo.ts`. `components/seo/Analytics.tsx` loads it
  and sends a `generate_lead` event for WhatsApp, email and phone taps.
