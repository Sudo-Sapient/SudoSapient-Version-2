# Sudo Sapient Website

Marketing site for **Sudo Sapient**, an AI transformation studio. Built with **Next.js 15**
(App Router), **React 19**, **TypeScript** and **Tailwind CSS**. The stickman animations
are **Rive** files generated by scripts in `scripts/rive/`.

## Quick start

```bash
npm install
npm run dev -- -p 4000
```

Open `http://localhost:4000`. The `dev` script is plain `next dev` (port 3000 by default);
the team passes `-p 4000`.

Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_FORMSPREE_ID` if you want the
contact form to send (see [Contact form](#contact-form)).

## Scripts

| Script                                    | Does                                                                        |
| ----------------------------------------- | --------------------------------------------------------------------------- |
| `npm run dev`                             | Local dev server                                                            |
| `npm run build` / `npm run start`         | Production build / serve it                                                 |
| `npm run lint` / `npm run lint:fix`       | ESLint                                                                      |
| `npm run typecheck`                       | `tsc --noEmit`                                                              |
| `npm run format` / `npm run format:check` | Prettier write / check                                                      |
| `npm run test` / `npm run test:watch`     | Vitest                                                                      |
| `npm run validate`                        | typecheck, lint, test, build. Run before every deploy                       |
| `npm run rive:<name>`                     | Rebuild `public/rive/<name>.riv` from `scripts/rive/<name>.mjs`             |
| `postinstall` (automatic)                 | Copies `rive.wasm` from `@rive-app/canvas` into `public/rive/` (gitignored) |

Rive scripts: `rive:hero`, `rive:strike`, `rive:portfolio`, `rive:transform`,
`rive:testimonials`, `rive:cta`, `rive:footer`, `rive:climber`, `rive:services`,
`rive:about`. See `docs/RIVE.md`.

## Stack

- Next.js 15 App Router, React 19, TypeScript, Tailwind CSS 3
- Rive (`@rive-app/react-canvas`) for the stickman scenes; `.riv` files generated with
  `rive-mcp-server`'s writer (devDependency)
- Framer Motion for UI motion; GSAP (ScrollTrigger, DrawSVG) for the ladder climber, the
  text reveals and the SVG fallback scenes; OGL for the WebGL grid in the home hero
- Radix UI (`Select`, `Slot`), `class-variance-authority`, `tailwind-merge`
- Fonts (`next/font/google` in `app/layout.tsx`):

| Font             | CSS variable     | Tailwind class | Used for                      |
| ---------------- | ---------------- | -------------- | ----------------------------- |
| Instrument Serif | `--font-serif`   | `font-serif`   | Headlines and statement lines |
| Archivo Black    | `--font-display` | `font-display` | Card titles, wordmark         |
| Archivo          | `--font-grotesk` | `font-sans`    | Body copy                     |
| IBM Plex Mono    | `--font-mono`    | `font-mono`    | Labels and technical text     |

## Contact form

`components/sections/ContactForm.tsx` posts the form to **Formspree** at
`https://formspree.io/f/${NEXT_PUBLIC_FORMSPREE_ID}`.

- Success: the form is replaced by `ContactSuccessScene`.
- Failure, or `NEXT_PUBLIC_FORMSPREE_ID` not set: an error message asks the visitor to
  email `sudosapient@gmail.com` directly. Nothing opens automatically.
- The ID is read at build time (`NEXT_PUBLIC_`), so it must be set in the build
  environment, including the GitHub Pages workflow.

## Copy rules

The owner wants all copy to follow these:

- No dashes as connectors (no em or en dashes between clauses). Use a full stop or a comma.
- No arrow characters.
- Never say "product".
- Position the studio as **AI transformation**: we sit with the team, learn how the work
  really gets done, automate the busywork with AI agents, and hand it over.
